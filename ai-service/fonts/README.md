Fonts used by the web app and the PDF engine, converted from the @fontsource packages (Latin subset).
Source Sans 3, Source Serif 4: SIL Open Font License 1.1 (Adobe). Great Vibes, Dancing Script: SIL OFL 1.1.
deploy/install.sh copies them to /usr/local/share/fonts/bidcraft so WeasyPrint uses the same faces as the screen.
